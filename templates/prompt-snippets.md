# Premium Commercial PPT 提示词模板

## 1. 从主题生成商用成片

```text
请按 premium-commercial-ppt skill 的标准，为以下主题生成一套客户可交付的商用 PPTX。

主题：{主题}
使用场景：{场景}
目标受众：{受众}
决策目标：{目标}
建议页数：{页数，默认 8-12 页}
材料：{材料或“暂无”}

要求：
1. 先提炼受众、决策目标、行业、事实、痛点、能力、价值和缺失信息。
2. 先写 claim spine，再生成逐页 deck plan。
3. 每页必须有一个 claim 和一个 proof object。
4. 默认 style 使用 premium-commercial-keynote。
5. 生成真实 .pptx，并运行 validate_pptx.js；有条件时导出 preview PNG。
6. 不在 PPT 画面里出现“示例、测试稿、验收稿、占位、待补充”。
7. 不编造数据、客户、案例、政策或奖项。
```

## 2. 长材料整理成高端 PPT

```text
请将以下材料整理成一套高级商用 PPT。不要简单摘要材料，要重构成可汇报、可销售、可决策的商业叙事。

材料：
{粘贴材料}

输出要求：
- 提取事实、矛盾、机会、能力、实施路径、价值主张和风险。
- 生成 4-6 个章节和 8-12 页页面结构。
- 每页标题必须是结论式 claim。
- 每页说明 proof object：架构图、流程图、矩阵、价值信号、风险坐标、对比结构或数据图。
- 不编造缺失事实；缺失信息放在交付说明。
```

## 3. 优化已有 PPT 文案

```text
请按高级商用 PPT 标准优化以下逐页文案。

原文：
{粘贴逐页文案}

输出要求：
- 先判断每页是否有明确 claim。
- 合并重复页，拆分过载页，删除水话。
- 把普通标题改成结论式标题。
- 给出每页 proof object 和版式方向。
- 标出哪些页面需要重构，而不是只润色文字。
```

## 4. 客户解决方案 PPT

```text
请为以下产品/服务生成一套面向客户决策层的高端解决方案 PPTX。

产品/服务：{产品或服务}
客户行业：{行业}
客户痛点：{痛点}
目标受众：{客户决策层/业务部门/技术部门}
已有材料：{材料}

输出要求：
- 先讲客户问题和业务变化，再讲方案。
- 包含现状判断、关键问题、总体架构、能力地图、实施路径、预期价值、风险保障。
- 每页必须有 proof object，不要全做卡片。
- 生成真实 PPTX 并验证。
```

## 5. 质量审核

```text
请按 premium-commercial-ppt 的质量标准审核以下 PPT 内容或 deck plan。

内容：
{粘贴内容}

请从以下维度给出判断：
1. 商业主线是否清楚
2. 每页 claim 是否成立
3. proof object 是否足够
4. 页面族节奏是否重复
5. 是否像高级商用成片，而不是模板/后台 UI/材料摘要
6. 是否存在事实编造或可见占位词

最后输出优先重构清单。
```
